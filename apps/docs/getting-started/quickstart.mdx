# Quickstart

You will have your first semantic diff in under a minute. It takes two files and one command.

## Step 1: Create two files

Create `before.ts` and `after.ts`. The example function is renamed and gains a parameter:

```typescript
// before.ts
export function computeTotal(items: Item[]): number {
  return items.reduce((acc, item) => acc + item.price, 0);
}

export const TAX_RATE = 0.08;
```

```typescript
// after.ts
export function calculateTotalAmount(items: Item[], discount: number): number {
  const base = items.reduce((acc, item) => acc + item.price, 0);
  return base - discount;
}

export const TAX_RATE = 0.08;
```

## Step 2: Run the diff

<CodeGroup>
```bash Terminal
differens before.ts after.ts
```
```bash npx (no install)
npx differens before.ts after.ts
```
</CodeGroup>

## Step 3: Read the output

```text
rename: function `computeTotal` -> `calculateTotalAmount`
insert: parameter `discount` in function `calculateTotalAmount`
insert: statement `const base = ...` in function `calculateTotalAmount`
update: return expression: `items.reduce(...)` -> `base - discount`
match: export `TAX_RATE` (unchanged)
```

Compare that to a line diff of the same change:

```diff
- export function computeTotal(items: Item[]): number {
-   return items.reduce((acc, item) => acc + item.price, 0);
+ export function calculateTotalAmount(items: Item[], discount: number): number {
+   const base = items.reduce((acc, item) => acc + item.price, 0);
+   return base - discount;
  }
```

The line diff reports the whole function as deleted and rewritten. Differens reports a rename, an added parameter, an added statement, an updated expression, and an unchanged `TAX_RATE`.

<Info>
Each action in the output is a typed edit: `rename`, `move`, `insert`, `delete`, `update`. The narration engine produces these from the Chawathe edit script computed by the matching core.
</Info>

## Step 4: Try JSON output

Machine-readable output, one typed action per entry:

<CodeGroup>
```bash Command
differens before.ts after.ts --format=json
```
```json Output
{
  "actions": [
    { "kind": "rename", "node": "function", "from": "computeTotal", "to": "calculateTotalAmount" },
    { "kind": "insert", "node": "parameter", "name": "discount" },
    { "kind": "insert", "node": "statement", "detail": "const base = ..." },
    { "kind": "update", "node": "return", "detail": "items.reduce(...) -> base - discount" }
  ],
  "files": ["before.ts", "after.ts"]
}
```
</CodeGroup>

## Step 5: Diff a git working tree

Run Differens inside a git repository. It diffs the working tree against `HEAD` and correlates moves across all changed files:

<CodeGroup>
```bash Command
cd your-project
differens
```
```text Output (excerpt)
diff: src/utils.ts -> src/helpers/math.ts
move: function `computeTotal` -> `calculateTotalAmount` (across files)
insert: parameter `discount` in function `calculateTotalAmount`
```
</CodeGroup>

You can also diff a commit range instead:

```bash
differens main..feature
```

## Step 6: Diff two directories

Compare two whole directories. Differens matches files across the trees and reports renames at the file level too:

<CodeGroup>
```bash Command
differens old/ new/
```
```text Output (excerpt)
move: src/utils.ts -> src/helpers/math.ts
rename: interface `CartItem` -> `LineItem` in src/models.ts
match: 142 of 150 files unchanged
```
</CodeGroup>
