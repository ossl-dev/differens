The C# extractor maps tree-sitter C# CST nodes to canonical concepts. Class, method, and namespace names come from the standard `name` field; variable names come from the declarator.

## Detected concepts

| tree-sitter node type | Canonical concept |
|---|---|
| `class_declaration` | Class |
| `namespace_declaration` | Namespace |
| `using_directive` | Import |
| `method_declaration` | Method |
| `variable_declaration` | Variable |
| `parameter_list` | Parameters |
| `invocation_expression` | CallExpression |
| `member_access_expression` | MemberAccess |
| `conditional_expression` | TernaryOp |
| `predefined_type` | TypeIdentifier |
| `string_literal` | string_literal |
| `integer_literal` | integer_literal |

## Example

Renaming a method:

```csharp old.cs
class Counter { int Total(int n) { return n + 1; } }
```

```csharp new.cs
class Counter { int Sum(int n) { return n + 1; } }
```

Running `differens old.cs new.cs`:

```text
  ~ renamed method `Total` to `Sum` in class `Counter`
```

## Example: change the body

Keep the declaration name and change what it does:

<CodeGroup>

```csharp body-before.cs
class Counter { int Total(int n) { return n + 1; } }
```

```csharp body-after.cs
class Counter { int Total(int n) { return n + 2; } }
```

</CodeGroup>

```bash
differens body-before.cs body-after.cs
```

```text
  ~ changed method `Total` (`1` → `2`)
```

The report groups the value edit under its containing declaration. Use
`--format=json` to inspect the underlying action and context, or `--format=llm`
for a compact report with source locations.

## Known limitations

- Partial classes across files are correlated per file; the cross-file correlator pairs moved members when the whole changeset is diffed at once.
- LINQ query syntax uses its grammar nodes where no canonical concept mapping exists; the extractor does not infer query behavior.
